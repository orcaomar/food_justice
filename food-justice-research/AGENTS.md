# AGENTS.md - Food Justice Research Engineering Guide

This document contains architectural context, infrastructure configuration, performance findings, and operational guidelines for agents working on the `food-justice-research` repository.

---

## 1. Project Overview & Architecture

- **Domain**: [https://foodjusticeresearch.ca](https://foodjusticeresearch.ca)
- **Primary Subdirectory**: `food-justice-research/`
- **Application Type**: Client-side Single Page Application (SPA) built with **React 18** and **Vite**.
- **Production Hosting**: **Cloudflare Pages** (Project: `food-justice-research`, automatic CI builds from GitHub `main` branch).
- **Previous Hosting**: Fly.io (`food-justice-research`) — *decommissioned*.
- **No Backend**: There is no server-side Node.js/Python API or database in this repository. All data is static JSON/JS modules inside `src/data/`.

## 3. Production Hosting & Deployment (Cloudflare Pages)

The application is deployed as a static Single Page Application (SPA) on Cloudflare Pages:

- **Build Command**: `npm run build`
- **Build Output Directory**: `dist`
- **Root Directory**: `food-justice-research`
- **Node Version**: 20.x / 22.x
- **CI/CD**: Cloudflare Pages connects directly to the GitHub repository and triggers builds on pushes to `main`.
- **Global Edge & Caching**: Assets under `dist/assets/` contain content hashes generated by Vite, allowing Cloudflare's edge network to cache them immutably.
- **Routing**: Single Page Application routing is handled by React Router; Cloudflare Pages serves `index.html` for client-side navigation.

### Decommissioning Fly.io:
To tear down the legacy Fly.io application and release all provisioned Fly resources/machines:
```bash
fly apps destroy food-justice-research
```
(Or run `fly apps destroy food-justice-research --yes` to confirm automatically).

## 4. Media & Asset Performance Optimization

### 1. Hero Background Video (`src/assets/homepage/background_video.mp4` - 4.43 MB):
- Imported in `src/components/Hero.jsx`.
- Has a poster image and metadata preloading. On mobile viewports, consider disabling video autoplay and rendering the poster image to conserve mobile data.

### 2. Challenge Images:
- Images in `src/data/` utilize `vite-imagetools` (`?w=400;800;1200&format=webp;jpg&srcset`) with `<ResponsiveImage />` to deliver responsive WebP variants.

### 3. Spoken Audio Files (`src/assets/audio/`):
- Interview quote overlays use `<audio>` elements with `preload="none"` so audio is only streamed when explicitly played by the user.

## 5. Development & Testing Workflow

All development commands are run from the `food-justice-research/` directory:

- **Development Server**: `npm run dev` (starts Vite local dev server at `http://localhost:5173`)
- **Unit & Integration Tests**: `npm run test -- --run` (runs Vitest test suites)
- **Production Build**: `npm run build` (bundles the app into `dist/`)
- **Local Preview**: `npm run preview` (previews production build locally)
